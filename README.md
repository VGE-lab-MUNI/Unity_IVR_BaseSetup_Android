\# Unity IVR Base Setup (Android)



Reusable Unity IVR project foundation for Android devices.



\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_



\## Unity Version



Unity 6.x (currently 6000.3.11f1 LTS)



\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_



\## Purpose



This repository serves as a reusable starting point for Unity IVR projects (mainly for Android-based devices – Meta Quest 2/3/3S/Pro; PICO Neo 3; PICO 4; etc.).

The idea of this project is to minimize or eliminate the effort required to set up the base packages and settings when creating a new Unity IVR project, so the user can start developing right away without needing to set everything up themselves.



\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_



\## Main Packages Included



\- Unity Input System

\- XR Interaction Toolkit

\- XR Plugin Management

\- Unity OpenXR Meta

\- OpenXR Plugin

– PICO Unity Integration SDK (external)
